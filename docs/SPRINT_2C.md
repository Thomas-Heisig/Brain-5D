# Sprint 2C - Three-factor plasticity and Heatmap Observatory

Version: 0.3.0

Sprint 2C adds reward-modulated three-factor plasticity on top of the signed
eligibility traces introduced in Sprint 2B. The core remains learning-neutral;
plasticity runs through the generic post-step hook.

## Rule

`delta_w = learning_rate * reward * eligibility`

Eligibility is signed. Positive and negative correlations therefore both
participate in reward-modulated learning. Delayed rewards decay the trace to
the reward due tick before applying the update.

## Reward modes

- `reward_source: external` - no automatic reward is generated by `main.py`.
- `reward_source: output_spike` - an output spike generates the configured
  `output_spike_value` reward.

Direct STDP and three-factor learning remain separately switchable. For a pure
three-factor experiment use `stdp.enabled: false`, `eligibility.enabled: true`
and `reward.enabled: true`.

## Heatmap

The Observatory now offers activity, incoming-weight and energy projections on
the X-Y plane. Data projection is separated from Matplotlib rendering so the
numerics can be tested headlessly.

## Verification

```powershell
python -m pytest tests/test_reward.py -v
python -m pytest tests/test_heatmap.py -v
python -m pytest tests -v
python -m src.main --observe
```

Quality tools are defined in `pyproject.toml`:

```powershell
black --check src tests
pylint src/learning src/visualization/heatmap.py
mypy src/learning src/visualization/heatmap.py
```

The legacy Sprint 1C modules are currently excluded from strict mypy checking;
strict typing is enforced incrementally on the new learning and heatmap layer.
