## Reproduktion und Versionierung

[Methodenprüfskript](methodenpruefung.py), [tatsächlicher Beispielbericht](methodenpruefung.json) und [BibTeX-Nachtrag](literatur_revision.bib) ergänzen die Kapitel. Die 28 deterministischen Prüfungen sind keine Brain-5D-Lernversuche. Hypothesen und EVID-Einträge bleiben im kanonischen Forschungsregister; die Publikation besitzt keine automatische Freigabeautorität.

Vom Repository-Hauptverzeichnis:

```bash
python scripts/publication_revision.py
python scripts/publication_revision.py --export /tmp/Brain5D_Abhandlung_v1.1.md
```

Der Export ist eine abgeleitete Lesefassung, keine zweite Bearbeitungsquelle. Die unveränderte Word-Datei und das ZIP der Fassung 1.0 bleiben historische Artefakte. Für diese Revision wird keine aktualisierte DOCX-Datei behauptet. Unabhängiges inhaltliches Fachreview ist vom technischen Editionscheck zu unterscheiden.
